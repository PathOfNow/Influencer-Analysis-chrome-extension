1. 它能干什么

这是一款 Chrome 浏览器插件，专门帮你分析 Instagram 红人，一共三个核心功能：

功能作用需要打开的页面
寻找红人批量寻找竟对品牌合作过的红人账号Instagram 用户主页 tagged 标签页
红人画像分析红人是否是优质红人Instagram 用户主页
相似红人基于目标红人推荐同类型优质红人Instagram 用户主页

采集完成后，可以一键导出 Excel（CSV）文件。

2. 安装前准备

2.1 你需要准备的东西

  1. 一台电脑（Windows / Mac 都可以）
  2. Chrome 浏览器（或 Edge、360 等基于 Chromium 的浏览器）
  3. 一个 Google 账号（用于登录插件）
  4. 一个 Instagram 账号（已经登录在浏览器里）
  5. 安装插件（谷歌应用商店搜索插件名称 pathofnow）

2.2 确认 Chrome 已登录 Instagram

  1. 打开 Chrome 浏览器
  2. 地址栏输入 https://www.instagram.com/ 回车
  3. 确认你已经登录了自己的 Instagram 账号（能看到首页动态就行）

如果没登录 Instagram，插件没法采集数据。

3. 安装插件

3.1 打开谷歌应用商店

  1. 在 Chrome 地址栏输入下面这串地址，回车：
    https://chromewebstore.google.com/search/pathofnow?hl=zh-CN&authuser=0
  2. 搜索结果会展示 :Instagram 红人分析助手 - pathofnow 。
  3. 鼠标点击，会跳转到插件详情和安装页，点击 添加至 Chrome 进行安装

3.2 确认安装成功

安装成功后，你会看到：

  • 扩展列表里多了一个叫「🚀 Instagram 红人分析助手 - pathofnow」的卡片
  • Chrome 工具栏右上角会出现一个插件图标（可能藏在拼图图标里）

3.3 把插件图标固定到工具栏（推荐）

  1. 点击 Chrome 工具栏右上角的拼图图标 🧩
  2. 找到「Instagram 红人分析助手」
  3. 点击它右边的图钉图标📌，把它固定到工具栏

固定后，以后点一下图标就能打开侧边栏，很方便。

3.4 打开侧边栏

点击工具栏上的插件图标，浏览器右侧会弹出一个侧边栏，这就是插件的操作界面。

如果点击没反应，看常见问题。

4. 登录流程

必须先登录，才能使用所有功能。

4.1 点击登录按钮

打开侧边栏后，在顶部你会看到一个蓝色按钮：

[ 使用谷歌账户登录 ]

点击它。

4.2 完成 Google 登录

点击后：

  1. 浏览器会弹出一个 Google 登录窗口
  2. 选择你的 Google 账号（或输入账号密码登录）
  3. 如果提示「是否允许」，点「允许」/「继续」

4.3 登录成功后的样子

登录成功后，顶部会显示：

  • 你的头像（名字首字母）
  • 你的名字
  • 你的邮箱
  • 授权状态标签（下面会讲）

4.4 登录失败怎么办

如果登录失败，顶部会显示红色错误提示，常见原因：

  • 网络问题：确保能正常访问 Google
  • Google 账号未选择：重新点击登录按钮，选一个账号
  • 弹窗被拦截：允许浏览器弹窗
  • 后端服务器连接失败

如果是登录谷歌失败可以重试，多试几次。

如果是后端服务连接失败，点右侧的「获取授权」按钮重试。

5. 购买授权码

登录 Google 只是身份验证，还要购买授权码并核销，才能真正使用功能。

5.1 点击购买按钮

在侧边栏顶部右侧，找到红色按钮：

[ 购买授权码 ]

点击它，会打开一个新网页（购买页面）。

5.2 完成购买

在打开的购买页面里，按照网站提示完成支付，你会获得一串授权码（一串字母数字组合的字符串）。

请保存好这个授权码，后面核销要用。

5.3 授权状态说明

在侧边栏顶部，你会看到一个授权状态标签：

标签颜色含义
已授权绿色授权有效，可以使用所有功能
未授权灰色还没核销授权码，需要先购买并核销

旁边还会显示「到期: YYYY-MM-DD」，告诉你授权什么时候到期。

6. 授权码核销（激活）

买到授权码后，必须核销才能激活授权。

6.1 点击核销按钮

在侧边栏顶部右侧，找到蓝色按钮：

[ 授权码核销 ]

点击它，会弹出一个输入框。

6.2 输入授权码

在弹出的输入框里，粘贴或输入你购买时获得的授权码。

6.3 确认核销

点击「确定」按钮。

  • 核销成功：输入框关闭，顶部授权状态变成绿色的「已授权」，并显示到期日期
  • 核销失败：输入框下方会显示红色错误原因，常见原因：
    • 授权码输入错误 → 检查后重新输入
    • 授权码已被使用 → 一个授权码只能用一次
    • 授权码已过期 → 联系卖家
    • 未登录 → 先完成 Google 登录

6.4 核销成功后

核销成功后，插件会自动刷新授权状态。如果没自动刷新，点击右上角的「获取授权」按钮手动刷新。

7. 功能一：寻找红人（Tagged）

作用：批量采集某个账号被标记（Tagged）的所有帖子里的红人信息。

7.1 第一步：打开 Tagged 页面

  1. 在 Chrome 中打开 Instagram
  2. 打开某个账号的 Tagged 页面，网址格式是这样的：
    https://www.instagram.com/用户名/tagged/

举个例子，要采集 nike 被标记的帖子，就打开：

https://www.instagram.com/nike/tagged/

怎么找到 Tagged 页面？
1. 打开某个用户的主页
2. 在主页上方有一排标签：帖子、Reels、Tagged（被标记）
3. 点击「Tagged」标签
4. 看浏览器地址栏，网址后面应该有 /tagged/

7.2 第二步：切换到「寻找红人」标签页

在侧边栏中间，有一排三个大标签：

[ 寻找红人 ]  [ 红人画像 ]  [ 相似红人 ]

点击最左边的「寻找红人」。

7.3 第三步：确认页面状态正确

切换标签后，上方会显示状态提示：

  • ✅ 正常：显示「请在 Instagram Tagged 页面点击开始分析」，开始按钮可点击
  • ❌ 页面不对：显示红色提示，开始按钮灰色不可点
    • 解决：确认网址里有 /tagged/，重新打开正确的 Tagged 页面

7.4 第四步：点击「开始分析」

点击蓝色的「开始分析」按钮。

点击后：

  1. 按钮变成灰色不可点
  2. 「停止」按钮变成红色可点
  3. 状态提示变成「正在收集帖子...」
  4. 页面会自动滚动，收集所有帖子的链接
  5. 下方日志会实时显示进度

重要：收集帖子阶段，请保持这个页面在屏幕上可见，不要切到别的标签页，否则滚动可能停下来。

7.5 第五步：等待分析

收集完帖子后，插件会自动开始逐个分析每个帖子的作者：

  1. 状态变成「分析中」
  2. 进度条和统计数字会实时更新
  3. 「当前处理红人」会显示正在分析的用户名
  4. 日志会显示每个帖子的分析结果

分析阶段比较长（每个帖子要打开页面提取数据），可以最小化浏览器窗口去做别的事，后台会继续跑。

7.6 停止分析（可选）

首次点击「停止」按钮

  1. 立即停止滚动收集待分析帖子数
  2. 开始分析帖子红人数据

第二次点击「停止」按钮

  1. 立即停止分析帖子红人数据
  2. 分析流程结束,可以导出已分析的数据

7.7 统计数据说明

在分析过程中，上方会显示四个统计卡片：

卡片含义
待分析一共收集到多少个帖子
已分析已经分析完多少个
成功成功提取到数据的数量
失败提取失败的数量

7.8 分析完成

全部分析完成后：

  • 状态变成「已完成」
  • 「开始分析」按钮恢复可点
  • 「停止」按钮变灰
  • 「导出 Excel」按钮变亮可点
  • 日志显示「分析完成！成功:XX 失败:XX」

7.9 导出结果

点击「导出 Excel」按钮，会自动下载一个 CSV 文件，包含以下字段：

字段说明
帖子链接帖子的 URL
时间帖子发布时间
点赞点赞数
评论评论数
Tagged账户被标记的账号
用户名帖子作者的用户名
位置帖子地理位置
主页链接作者的主页 URL
昵称作者的昵称
粉丝数作者的粉丝数
邮箱作者的邮箱（如果能找到）
红人类型作者的内容分类
媒体类型帖子类型（图片/视频）

CSV 文件可以用 Excel、WPS、Numbers 等表格软件打开。

8. 功能二：红人画像（Reels）

作用：分析某个红人的 Reels 数据，统计平均播放、评论、点赞数。

8.1 第一步：打开用户主页

  1. 在 Chrome 中打开 Instagram
  2. 打开某个红人的主页，网址格式：
    https://www.instagram.com/用户名/

比如要分析 cristiano，就打开：

https://www.instagram.com/cristiano/

不需要手动点 Reels 标签，插件会自动跳转。

8.2 第二步：切换到「红人画像」标签页

在侧边栏点击中间的「红人画像」标签。

8.3 第三步：确认页面状态

  • ✅ 正常：显示「请打开用户主页，点击 Reels 图标触发数据加载后开始分析」
  • ❌ 页面不对：确认网址是用户主页（不是帖子页、不是 Tagged 页）

8.4 第四步：点击「开始分析」

点击蓝色的「开始分析」按钮。

点击后：

  1. 插件自动跳转到该用户的 /reels/ 页面
  2. 页面开始自动滚动，收集 Reels 数据
  3. 日志显示「正在收集 Reels 数据...」

重要：收集阶段保持页面可见，不要切换标签页。

8.5 第五步：等待分析

Reels 分析会：

  1. 滚动页面触发 Instagram 加载更多 Reels
  2. 拦截 Instagram 的数据接口，收集每个 Reels 的播放数、点赞数、评论数
  3. 实时更新进度和统计

8.6 停止分析（可选）

点击「停止」按钮

  1. 立即停止滚动收集reels 视频的互动数据
  2. 开始分析已经的收集reels 视频的红人互动数据
  3. 分析流程结束,可以导出已分析的数据

8.7 统计数据说明

上方四个统计卡片：

卡片含义
粉丝数该红人的粉丝数量
平均播放数所有 Reels 的平均播放数
平均评论数所有 Reels 的平均评论数
平均点赞数所有 Reels 的平均点赞数

8.8 分析完成

完成后：

  • 状态变成「已完成」
  • 「导出 Excel」按钮变亮
  • 日志显示完成信息

8.9 导出结果

点击「导出 Excel」按钮，下载的 CSV 文件包含：

字段说明
红人账户名称用户名
红人主页地址主页 URL
粉丝数粉丝数量
平均播放数Reels 平均播放
平均评论数Reels 平均评论
平均点赞数Reels 平均点赞
分析帖子数分析了多少个 Reels

9. 功能三：相似红人

作用：找出和某个红人相似的其他红人，并采集他们的详细信息。

9.1 第一步：打开用户主页

和「红人画像」一样，先打开某个红人的主页：

https://www.instagram.com/用户名/

9.2 第二步：切换到「相似红人」标签页

9.3 第三步：确认页面状态

  • ✅ 正常：显示「请打开用户主页后点击开始分析」
  • ❌ 页面不对：确认网址是用户主页

9.4 第四步：点击「开始分析」

点击蓝色的「开始分析」按钮。

点击后：

  1. 插件自动点击页面上的「类似账户」按钮
  2. 弹出相似红人列表
  3. 自动翻页收集所有相似红人的用户名
  4. 日志显示「正在收集相似红人数据...」

重要：收集阶段保持页面可见。

9.5 第五步：等待分析

收集完相似红人列表后，插件会逐个打开每个相似红人的主页，提取：

  • 粉丝数
  • 邮箱
  • 红人类型
  • 是否认证
  • 位置等

这个过程比较慢（每个红人都要打开主页），可以最小化窗口，后台会继续跑。

9.6 停止分析（可选）

  1. 立即停止滚动收集待分析红人数

第二次点击「停止」按钮

  1. 立即停止分析红人数据

10. 导出数据

三个功能都有独立的「导出 Excel」按钮，用法一样。

10.1 什么时候可以导出

  • 分析完成（或中途停止）后
  • 「导出 Excel」按钮变亮（不再灰色）时可以点
  • 必须有数据才能导出，否则会提示「没有可导出的数据」

10.2 怎么导出

  1. 确认分析已完成或有数据
  2. 点击对应功能的「导出 Excel」按钮
  3. 浏览器自动下载一个 CSV 文件
  4. 文件名格式：
    • 寻找红人：instagram_tagged_report_日期.csv
    • 红人画像：instagram_reels_report_日期.csv
    • 相似红人：similar_accounts_日期.csv

10.3 打开导出的文件

CSV 文件用 Excel / WPS / Numbers 打开即可。

如果中文乱码，用 Excel 打开时选择「UTF-8」编码，或者用 WPS 打开（自动识别编码）。本插件导出的文件已经加了 BOM 头，一般不会乱码。

10.4 没有数据怎么办

如果点击导出提示「没有可导出的数据」：

  1. 检查是否真的运行过分析
  2. 检查分析是否成功（看统计卡片的「成功」数量）
  3. 如果全是失败，可能是页面加载问题，重新运行一次

11. 停止任务

11.1 什么时候需要停止

  • 收集的帖子/相似红人已经够多了，不想继续收集
  • 分析的数据已经够多了，不想继续分析了
  • 发现页面不对，想重来

11.2 怎么停止

点击红色的「停止」按钮。

11.3 停止的两种情况

插件停止分两个阶段，行为不同：

情况一：正在收集帖子时停止（状态显示「收集中」）

  • 停止继续滚动收集
  • 已收集的帖子会继续被分析（不会丢掉已收集的数据）
  • 日志显示「停止滚动，开始分析已收集的帖子」
  • 然后自动进入分析阶段

简单说：收集阶段点停止，相当于「够多了，开始分析这些」。

情况二：正在逐个分析时停止（状态显示「分析中」）

  • 立即停止分析
  • 已分析的结果会保留
  • 日志显示「已停止」
  • 可以直接导出已分析的数据

11.4 停止按钮防误触

同一个阶段（收集 / 分析），停止按钮只能点一次，点完会变灰。

如果从「收集」进入「分析」阶段，停止按钮会重新亮起，可以再点一次停止分析。

11.5 三个功能不能同时运行

同一时间只能运行一个功能（寻找红人 / 红人画像 / 相似红人）。

  • 一个功能在运行时，其他两个功能的「开始分析」按钮会变灰
  • 必须等当前任务完成或停止后，才能开始另一个

13. 常见问题

13.1 点击工具栏图标没反应

原因：侧边栏没启用。

解决：

  1. 打开 chrome://extensions/
  2. 找到本插件
  3. 点击「详情」
  4. 确认「允许侧边栏」已开启
  5. 重新点击工具栏图标

13.2 提示「请先登录」

原因：还没登录 Google，或登录已过期。

解决：

  1. 点击顶部「使用谷歌账户登录」按钮
  2. 完成 Google 登录
  3. 如果已登录过，点击「获取授权」按钮刷新

13.3 提示「当前账号未授权」

原因：登录了但没核销授权码。

解决：

  1. 点击「购买授权码」购买
  2. 点击「授权码核销」输入授权码
  3. 核销成功后点「获取授权」刷新

13.4 提示「会员已过期」

原因：授权到期了。

解决：重新购买授权码并核销。

13.5 开始分析按钮是灰色的

原因：

  • 没登录或没授权 → 先登录核销
  • 页面不对 → 打开正确的页面（看各功能要求）
  • 有其他任务在运行 → 等当前任务完成或停止

13.6 提示「请在 Instagram Tagged 页面点击开始分析」

原因：寻找红人功能需要打开 /tagged/ 页面。

解决：

  1. 打开某个用户主页
  2. 点击上方的「Tagged」标签
  3. 确认地址栏网址里有 /tagged/

13.7 提示「请打开用户主页」

原因：红人画像 / 相似红人需要打开用户主页。

解决：打开 https://www.instagram.com/用户名/ 格式的网址。

13.8 点击开始分析，滚动失败

点击开始分析后，如果滚动失败或者收集不到数据，请刷新页面重试

13.9 分析卡住不动

可能原因：

  • 网络慢 → 耐心等待
  • 页面被切到后台 → 切回来保持页面可见
  • Instagram 限制 → 等一会儿再试

解决：

  1. 看日志最后一条信息
  2. 如果真的卡死，点「停止」结束任务
  3. 重新开始

13.10 导出提示「没有可导出的数据」

原因：还没分析出结果。

解决：

  1. 先运行分析
  2. 等分析有结果（统计卡片「成功」数量大于 0）
  3. 再点导出

13.11 分析结果很多失败

可能原因：

  • 网络不稳定
  • Instagram 页面结构变化
  • 分析太快被限制

解决：

  1. 换个网络环境
  2. 减少分析数量
  3. 分多次分析

13.12 侧边栏关闭后状态丢失

不用担心。侧边栏关闭后，后台任务会继续运行。重新打开侧边栏会自动恢复状态和进度。

13.13 浏览器重启后还能恢复吗

可以。插件有断点续传功能：

  • 分析进度会自动保存
  • 浏览器重启后，重新打开侧边栏会显示之前的进度
  • 可以从断点继续分析

13.14 联系客服

点击侧边栏右上角的「帮助」按钮：

  • 「📖 操作手册」：查看在线文档
  • 「📧 联系我们」：显示联系方式（微信: pathofnow）

14. 账号安全建议

14.1 控制分析数量

侧边栏底部有黄色安全提示：

⚠️ 重要：账号安全 大规模频繁分析可能会触发 Instagram 频率限制。

建议每天分析数量：

功能建议每日上限
寻找红人不超过 500 个
相似红人不超过 160 个
红人画像无严格限制（单次分析）

14.2 其他建议

  1. 不要短时间内反复分析：分析完一个账号，等一会儿再分析下一个
  2. 使用小号：如果担心主号被限制，可以用 Instagram 小号操作
  3. 网络环境：建议使用稳定的网络，避免频繁掉线
  4. 不要同时开多个分析：插件已限制同时只能运行一个功能

14.3 如果被 Instagram 限制

症状：

  • 页面提示「请稍后再试」
  • 无法加载更多内容
  • 分析全部失败

解决：

  1. 停止当前分析
  2. 关闭浏览器，等待几小时甚至一天
  3. 期间可以正常使用 Instagram（不要分析）
  4. 解除限制后再继续
