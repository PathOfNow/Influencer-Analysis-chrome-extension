插件介绍

Instagram 红人分析助手是一款专为品牌营销人员设计的浏览器插件，帮助用户在 Instagram 平台上高效发现和分析红人资源。

插件提供三大核心功能模块：

  • 寻找红人：在 Tagged 页面批量发现合作过的红人账号
  • 红人画像：深入分析红人账号的粉丝数、播放量等关键数据
  • 相似红人：基于目标红人推荐同类型创作者

快速开始

第一步：安装插件

安装指南

第二步：登录授权

点击浏览器工具栏中的插件图标，在弹出窗口中点击"使用谷歌账户登录"，登录后即可试用。

第三步：开始分析

打开 Instagram 网站，进入目标页面（Tagged 页面或用户主页），在插件窗口中选择对应的 Tab，点击"开始分析"按钮。

登录授权

插件顶部区域提供登录和授权管理功能：

🔹 使用谷歌账户登录

点击此按钮使用谷歌账户登录插件，登录后会显示账户信息（头像、名称、邮箱）。

🔹 授权状态显示

登录后显示授权状态：

  • 未授权：尚未输入有效授权码
  • 已授权：授权码有效，显示到期日期

🔹 授权码核销

点击此按钮弹出输入框，输入购买的授权码完成验证。

🔹 购买授权码

点击此按钮跳转到购买页面，获取插件使用授权码。

🔹 帮助

点击此按钮显示帮助菜单，包含操作手册链接和联系我们信息。

寻找红人 Tab

此 Tab 用于在 Instagram Tagged 页面分析合作账号，批量收集和分析品牌被标记的帖子作者。

功能说明

当您在 Instagram 上访问某个账号的 Tagged 页面（如 https://www.instagram.com/xxx/tagged/）时，此功能可以：

  • 自动滚动页面收集所有 Tagged 帖子
  • 逐个打开帖子提取作者信息
  • 分析每个作者的账号数据

统计指标

  • 待分析：已收集但尚未分析的帖子数量
  • 已分析：已完成分析的帖子数量
  • 成功：分析成功的帖子数量
  • 失败：分析失败的帖子数量

按钮说明

  • 开始分析：启动 Tagged 分析流程，自动滚动收集并分析帖子
  • 停止：第一次点击停止，将停止页面滚动收集并开始分析，第二次点击停止,将停止整个分析过程
  • 导出 Excel：将分析结果导出为 Excel 文件

使用步骤

  1. 打开 Instagram，进入目标账号的 Tagged 页面
  2. 点击插件图标，确保显示"已识别 Tagged 页面"
  3. 点击"开始分析"按钮
  4. 等待分析完成，查看统计数据和日志
  5. 点击"导出 Excel"保存结果

红人画像 Tab

此 Tab 用于深入分析单个红人账号的详细数据，获取粉丝数、播放量、互动率等关键指标。

功能说明

当您在 Instagram 上访问某个用户主页时，此功能可以：

  • 提取该用户的粉丝数量
  • 分析其 Reels 视频的平均播放数
  • 分析平均评论数和平均点赞数

统计指标

  • 粉丝数：该用户的总粉丝数量
  • 平均播放数：所有 Reels 视频的平均播放量
  • 平均评论数：所有 Reels 视频的平均评论数
  • 平均点赞数：所有 Reels 视频的平均点赞数

按钮说明

  • 开始分析：启动红人画像分析，加载 Reels 数据
  • 停止：停止当前正在进行的分析任务
  • 导出 Excel：将分析结果导出为 Excel 文件

使用步骤

  1. 打开 Instagram，进入目标红人主页
  2. 点击页面上的 Reels 图标，触发数据加载
  3. 点击插件图标，确保显示"已识别用户主页"
  4. 点击"开始分析"按钮
  5. 等待分析完成，查看统计数据
  6. 点击"导出 Excel"保存结果

相似红人 Tab

此 Tab 用于基于目标红人推荐同类型的创作者，帮助品牌拓展合作资源。

功能说明

当您在 Instagram 上访问某个用户主页时，此功能可以：

  • 收集该用户的相似账号推荐
  • 逐个分析相似账号的数据
  • 发现同类型的优质创作者

统计指标

  • 待分析：已发现但尚未分析的相似账号数量
  • 已分析：已完成分析的相似账号数量
  • 成功：分析成功的相似账号数量
  • 失败：分析失败的相似账号数量

按钮说明

  • 开始分析：启动相似红人分析，收集并分析相似账号
  • 停止：第一次点击停止，将停止页面滚动并开始分析，第二次点击停止,将完成整个分析过程
  • 导出 Excel：将分析结果导出为 Excel 文件

使用步骤

  1. 打开 Instagram，进入目标红人主页
  2. 点击插件图标，确保显示"已识别用户主页"
  3. 点击"开始分析"按钮
  4. 等待分析完成，查看统计数据和日志
  5. 点击"导出 Excel"保存结果

数据导出

所有分析结果都可以导出为 Excel 文件，方便进行后续处理和团队协作。

导出内容

  • 账号用户名和主页链接
  • 粉丝数量
  • 平均播放数、评论数、点赞数
  • 分析时间和状态

注意事项

  • 导出按钮仅在分析完成后可用
  • 建议定期导出数据，避免浏览器缓存丢失
  • 导出的 Excel 文件使用 UTF-8 编码，支持中文显示

使用技巧

  • 分析前请确保已登录 Instagram 账号，否则可能无法获取完整数据
  • Tagged 页面分析时，请耐心等待页面滚动收集完成
  • 红人画像分析需要先点击 Reels 图标加载视频数据
  • 分析过程中请保持 Instagram 页面在前台，避免浏览器限制后台操作
  • 如果分析失败，请查看日志窗口获取详细错误信息
  • 定期清理浏览器缓存可以提高插件稳定性
  • 授权码过期前会有提示，请及时续费
