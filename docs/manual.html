1. 它能干什么

这是一款 Chrome 浏览器插件，专门帮你分析 Instagram 红人，一共三个核心功能：

功能作用需要打开的页面
寻找红人批量寻找竟对品牌合作过的红人账号Instagram 用户主页 tagged 标签页
红人画像分析红人是否是优质红人Instagram 用户主页
相似红人基于目标红人推荐同类型优质红人Instagram 用户主页

采集完成后，可以一键导出 Excel（CSV）文件。

2. 安装前准备

2.1 你需要准备的东西

  1. 一台电脑（Windows / Mac 都可以）
  2. Chrome 浏览器（或 Edge、360 等基于 Chromium 的浏览器）
  3. 一个 Google 账号（用于登录插件）
  4. 一个 Instagram 账号（已经登录在浏览器里）
  5. 安装插件（谷歌应用商店搜索插件名称 pathofnow）

2.2 确认 Chrome 已登录 Instagram

  1. 打开 Chrome 浏览器
  2. 地址栏输入 https://www.instagram.com/ 回车
  3. 确认你已经登录了自己的 Instagram 账号（能看到首页动态就行）

如果没登录 Instagram，插件没法采集数据。

3. 安装插件

3.1 打开谷歌应用商店

  1. 在 Chrome 地址栏输入下面这串地址，回车：
    https://chromewebstore.google.com/search/pathofnow?hl=zh-CN&authuser=0
  2. 搜索结果会展示 :Instagram 红人分析助手 - pathofnow 。
  3. 鼠标点击，会跳转到插件详情和安装页，点击 添加至 Chrome 进行安装

3.2 确认安装成功

安装成功后，你会看到：

  • 扩展列表里多了一个叫「🚀 Instagram 红人分析助手 - pathofnow」的卡片
  • Chrome 工具栏右上角会出现一个插件图标（可能藏在拼图图标里）

3.3 把插件图标固定到工具栏（推荐）

  1. 点击 Chrome 工具栏右上角的拼图图标 🧩
  2. 找到「Instagram 红人分析助手」
  3. 点击它右边的图钉图标📌，把它固定到工具栏

固定后，以后点一下图标就能打开侧边栏，很方便。

3.4 打开侧边栏

点击工具栏上的插件图标，浏览器右侧会弹出一个侧边栏，这就是插件的操作界面。

如果点击没反应，看常见问题。

4. 登录流程

必须先登录，才能使用所有功能。

4.1 点击登录按钮

打开侧边栏后，在顶部你会看到一个蓝色按钮：

[ 使用谷歌账户登录 ]

点击它。

4.2 完成 Google 登录

点击后：

  1. 浏览器会弹出一个 Google 登录窗口
  2. 选择你的 Google 账号（或输入账号密码登录）
  3. 如果提示「是否允许」，点「允许」/「继续」

4.3 登录成功后的样子

登录成功后，顶部会显示：

  • 你的头像（名字首字母）
  • 你的名字
  • 你的邮箱
  • 授权状态标签（下面会讲）

4.4 登录失败怎么办

如果登录失败，顶部会显示红色错误提示，常见原因：

  • 网络问题：确保能正常访问 Google
  • Google 账号未选择：重新点击登录按钮，选一个账号
  • 弹窗被拦截：允许浏览器弹窗
  • 后端服务器连接失败

如果是登录谷歌失败可以重试，多试几次。

如果是后端服务连接失败，点右侧的「获取授权」按钮重试。

5. 购买授权码

登录 Google 只是身份验证，还要购买授权码并核销，才能真正使用功能。

5.1 点击购买按钮

在侧边栏顶部右侧，找到红色按钮：

[ 购买授权码 ]

点击它，会打开一个新网页（购买页面）。

5.2 完成购买

在打开的购买页面里，按照网站提示完成支付，你会获得一串授权码（一串字母数字组合的字符串）。

请保存好这个授权码，后面核销要用。

5.3 授权状态说明

在侧边栏顶部，你会看到一个授权状态标签：

标签颜色含义
已授权绿色授权有效，可以使用所有功能
未授权灰色还没核销授权码，需要先购买并核销

旁边还会显示「到期: YYYY-MM-DD」，告诉你授权什么时候到期。

6. 授权码核销（激活）

买到授权码后，必须核销才能激活授权。

6.1 点击核销按钮

在侧边栏顶部右侧，找到蓝色按钮：

[ 授权码核销 ]

点击它，会弹出一个输入框。

6.2 输入授权码

在弹出的输入框里，粘贴或输入你购买时获得的授权码。

6.3 确认核销

点击「确定」按钮。

  • 核销成功：输入框关闭，顶部授权状态变成绿色的「已授权」，并显示到期日期
  • 核销失败：输入框下方会显示红色错误原因，常见原因：
    • 授权码输入错误 → 检查后重新输入
    • 授权码已被使用 → 一个授权码只能用一次
    • 授权码已过期 → 联系卖家
    • 未登录 → 先完成 Google 登录

6.4 核销成功后

核销成功后，插件会自动刷新授权状态。如果没自动刷新，点击右上角的「获取授权」按钮手动刷新。

7. 功能一：寻找红人（Tagged）

作用：批量采集某个账号被标记（Tagged）的所有帖子里的红人信息。

7.1 第一步：打开 Tagged 页面

  1. 在 Chrome 中打开 Instagram
  2. 打开某个账号的 Tagged 页面，网址格式是这样的：
    https://www.instagram.com/用户名/tagged/

举个例子，要采集 nike 被标记的帖子，就打开：

https://www.instagram.com/nike/tagged/

怎么找到 Tagged 页面？
1. 打开某个用户的主页
2. 在主页上方有一排标签：帖子、Reels、Tagged（被标记）
3. 点击「Tagged」标签
4. 看浏览器地址栏，网址后面应该有 /tagged/

7.2 第二步：切换到「寻找红人」标签页

在侧边栏中间，有一排三个大标签：

[ 寻找红人 ]  [ 红人画像 ]  [ 相似红人 ]

点击最左边的「寻找红人」。

7.3 第三步：确认页面状态正确

切换标签后，上方会显示状态提示：

  • ✅ 正常：显示「请在 Instagram Tagged 页面点击开始分析」，开始按钮可点击
  • ❌ 页面不对：显示红色提示，开始按钮灰色不可点
    • 解决：确认网址里有 /tagged/，重新打开正确的 Tagged 页面

7.4 第四步：点击「开始分析」

点击蓝色的「开始分析」按钮。

点击后：

  1. 按钮变成灰色不可点
  2. 「停止」按钮变成红色可点
  3. 状态提示变成「正在收集帖子...」
  4. 页面会自动滚动，收集所有帖子的链接
  5. 下方日志会实时显示进度

重要：收集帖子阶段，请保持这个页面在屏幕上可见，不要切到别的标签页，否则滚动可能停下来。

7.5 第五步：等待分析

收集完帖子后，插件会自动开始逐个分析每个帖子的作者：

    <
