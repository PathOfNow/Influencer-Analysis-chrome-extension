安装指南

首选 Chrome 应用商店一键安装，安全又便捷

1

前往 Chrome 应用商店

点击上方「前往 Chrome 应用商店」或在商店直接搜索 KOL Finder。

2

添加至 Chrome

在 KOL Finder 插件详情页点击「添加至 Chrome」按钮并确认授权。

3

固定并开始使用

安装完成后，在浏览器右上角扩展程序列表中将图标固定，点击即可直接启动。

1

下载插件 ZIP 包

点击下方“下载 ZIP 包”按钮获取最新的插件安装文件。

2

解压文件

解压下载的 ZIP 压缩包至本地任意指定文件夹。

3

打开开发者模式

在 Chrome 地址栏输入 chrome://extensions 并开启右上角的「开发者模式」。

4

加载已解压的扩展程序

点击「加载已解压的扩展程序」，选择刚才解压的文件夹即可完成安装。
