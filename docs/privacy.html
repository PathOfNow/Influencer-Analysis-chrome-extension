Last Updated: July 28, 2026

Welcome to "Instagram Influencer Analytics Assistant" (hereinafter referred to as "this Extension"). This extension is developed and operated by PathOfNow (hereinafter referred to as "we"). We value your privacy and are committed to protecting your personal information. This Privacy Policy is intended to explain how we collect, use, store, and protect your information.

1. Data Collection & Usage

To provide influencer analytics and data aggregation services, this Extension only collects and processes data necessary for functionality upon your explicit action:

  • Personal Identification Information: When you sign in using your Google account, we obtain your public Profile information (such as Google User ID, Email) via chrome.identity. This information is strictly used for identity authentication, user license verification, and account identification. We never access or store your Google password.
  • Website Content & Instagram Public Data: When you actively click the "Start Analysis" button on Instagram, the Extension executes authorized operations on your client side:
    • Automatically smooth-scrolls the current page to read and collect publicly displayed influencer profile links.
    • Navigates to corresponding public influencer profile pages based on your selected list to parse publicly displayed data (e.g., public follower count, bio, similar recommendations) and public API response data (e.g., engagement rate data returned by /graphql/query).
    This data comes entirely from publicly accessible content on Instagram pages and is used solely to generate aggregated analytical reports and exportable spreadsheets. The Extension will never read your Instagram password, private DMs, or any non-public private data.
  • Local Storage: This Extension uses chrome.storage.local to temporarily store login status, current analysis progress, and configuration rules locally in your browser. This data resides entirely on your local device.

2. User Control & Automation Notice

Fully Transparent & Controllable Automation:

  • User-Initiated Trigger: All page scrolling, link extraction, and automatic profile navigation parsing are strictly initiated ONLY after the user manually clicks the "Start Analysis" button. The extension will never run silently in the background or scrape data without authorization.
  • Real-Time Awareness & Interruption: The sidebar interface displays a real-time progress dashboard (e.g., "Analyzing 3/20..."). Users can click the "Stop Analysis" button at any time to immediately terminate all automated navigation and data parsing requests (the first click stops collection, and the second click stops analysis).

3. Data Non-Sharing & Non-Resale Statement (Google User Data Compliance)

We strictly pledge:

  • We NEVER use any user data obtained through Google OAuth (such as email, identity identifiers) for advertising targeting, user profile reselling, or any commercial purpose unrelated to the core function of the extension.
  • We NEVER sell, rent, or transfer your personal information or collected public analysis data to any third party.
  • Data is processed internally only to complete the "Influencer Analysis" task initiated by you and to verify service authorization.

4. Permissions Justification

  • storage: Used to save local configurations, login tokens, and analysis progress, preventing state loss upon browser restarts.
  • identity: Strictly used to initiate the official Google OAuth sign-in flow for account authentication.
  • alarms: Used to handle periodic background tasks and sync task status to prevent unexpected session timeouts.
  • sidePanel: Used to display the primary operational UI, real-time analytics dashboard, and insights within the Chrome sidebar.
  • host_permissions (https://www.instagram.com/*): Required for chrome.tabs.query and chrome.tabs.onUpdated to listen for tab loading completion (status === 'complete') and inspect active tab URLs (e.g., /username/, /reels/, /tagged/) for pre-analysis page validity checks. Without this permission, Chrome redacts tab.url as undefined, causing page validation to fail. All non-Instagram tabs and browsing history remain completely unread and untouched.
  • host_permissions (https://pathofnow.cn/*): Required to connect to our backend API server to validate user Google authentication tokens, retrieve authorization status, and fetch up-to-date analysis configuration rules.

5. Data Security

We employ industry-standard encrypted transmission protocols (HTTPS/SSL) when transmitting data to our backend servers (pathofnow.cn). We implement strict security measures to protect your personal data from unauthorized access, disclosure, or alteration.

6. User Rights & Data Deletion

You reserve the right to manage or delete your data at any time:

  • You can click the "Stop" button on the interface at any time to interrupt any ongoing automatic parsing tasks.
  • You can uninstall this extension at any time via the Chrome Extension Management page. Upon uninstallation, all data stored locally by the extension will be automatically deleted.
  • To delete account records saved on our server, please contact us via email (451261884@qq.com).
