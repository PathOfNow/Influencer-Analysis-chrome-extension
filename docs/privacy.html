Welcome to "KOL Finder / Influencer Analytics Assistant" (hereinafter referred to as "this Extension"). This extension is developed and operated by PathOfNow (hereinafter referred to as "we"). We value your privacy and are committed to protecting your personal information. This Privacy Policy explains how we collect, use, store, and protect your information.

1. Data Collection & Usage

To provide influencer analytics, data aggregation, and outreach email sending services, this Extension only collects and processes necessary data upon your explicit trigger:

  • User Authentication & Basic Profile Data: When you sign in using your Google account, we obtain your public Profile information (such as Google User ID, Email) via chrome.identity. This information is transmitted securely to our backend server (pathofnow.cn) solely for user identity authentication, license validation, and account management. We never access or store your Google password.
  • Gmail API & Outreach Email Data (Client-Side Local Processing): To enable the direct outreach feature, this Extension requests access to the https://www.googleapis.com/auth/gmail.send scope.
    • Local Execution: All OAuth tokens and email composition/sending operations occur strictly within your browser (Chrome extension client-side).
    • No Remote Storage: We DO NOT transmit, store, or process your email content, recipient lists, or Gmail OAuth tokens on our servers or any third-party databases.
  • Public Creator Data & Website Content: When you click the "Start Analysis" button on supported social platforms (Instagram, YouTube, TikTok), the Extension reads publicly displayed creator metrics and public API responses locally to generate analytical reports. The Extension never reads private messages or non-public data.
  • Local Storage: This Extension uses chrome.storage.local to temporarily store login status, analysis progress, and configuration rules locally in your browser.

2. Google API Services User Data Policy Compliance (Limited Use)

Google API User Data Compliance Statement:

This Extension's use and transfer to any other app of information received from Google APIs will adhere to Google API Services User Data Policy, including the Limited Use requirements.

  • We ONLY use the gmail.send permission to send outreach emails directly initiated by you from the extension sidepanel interface.
  • We NEVER sell, rent, or transfer your Google user data or Gmail information to any third party.
  • We DO NOT use Google user data for advertising targeting, credit scoring, or user profiling.

3. User Control & Automation Transparency

  • User-Initiated Trigger: All data extraction, navigation, and email sending actions are strictly initiated ONLY after manual user interaction. The extension never runs silently in the background or sends unauthorized emails.
  • Real-Time Awareness & Interruption: The sidebar interface displays real-time progress. Users can click the "Stop" button at any time to immediately terminate active operations.

4. Permissions Justification

  • storage: Used to save local configurations, login tokens, and analysis progress locally.
  • identity: Used to initiate official Google OAuth sign-in flow for authentication.
  • gmail.send: Strictly used to send outreach emails directly from the user's Gmail account upon explicit user action.
  • scripting: Reads DOM elements on active target profile pages to extract publicly visible performance metrics locally.
  • sidePanel: Renders the primary operational UI, analytics dashboard, and email drafting interface in the Chrome sidebar.
  • host_permissions (Instagram, YouTube, TikTok): Required to target public creator profiles to render embedded analytics UI.
  • host_permissions (https://pathofnow.cn/*): Required to connect to our backend API server to validate user account tokens and retrieve license authorization status.

5. Data Security

We employ industry-standard encrypted transmission protocols (HTTPS/SSL) when transmitting account authentication data to our backend server (pathofnow.cn). All Gmail API operations remain isolated within your local browser environment.

6. User Rights & Account Deletion

  • You can interrupt any active task by clicking the "Stop" button in the extension UI.
  • You can uninstall this extension at any time via Chrome Extension Management, which automatically removes all local storage data.
  • To request deletion of your account credentials saved on our server, please contact us at 451261884@qq.com.
